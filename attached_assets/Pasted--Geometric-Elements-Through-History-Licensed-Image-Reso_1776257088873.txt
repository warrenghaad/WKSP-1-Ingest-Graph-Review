# Geometric Elements Through History: Licensed Image Resource Guide

A comprehensive collection of properly licensed, high-quality images with direct embeddable URLs for a 6-dimension geometry curriculum slideshow, sourced from major open access institutions.

## 1D Foundations: Early Mathematical Thinking

### Ishango Bone (20,000 BCE)
**Primary Image**: Royal Belgian Institute of Natural Sciences collection
- **Direct URL**: https://upload.wikimedia.org/wikipedia/commons/6/62/Os_d%27Ishango_IRSNB.JPG
- **Resolution**: 1,404 × 2,274 pixels (972 KB)
- **License**: CC BY-SA 3.0 / GFDL (GNU Free Documentation License)
- **Source**: Wikimedia Commons
- **Description**: Dark brown baboon fibula with engraved tally marks, one of earliest mathematical tools
- **Usage**: Attribution required, ShareAlike applies

### Babylonian Mathematical Tablets
**Primary Option**: Yale Babylonian Collection via CDLI
- **Object**: YBC 7290 (trapezoid area calculation tablet)
- **Source**: Cuneiform Digital Library Initiative (cdli.earth/cdli-tablet/739)
- **License**: Educational use with attribution to Yale Babylonian Collection
- **Period**: Old Babylonian (1900-1600 BCE)
- **Alternative**: Smithsonian replica of Plimpton 322 (nmah_690811) with CC0 designation

### Lascaux Cave Paintings
**Primary Source**: UNESCO/Wikimedia Commons (replica images)
- **Category**: commons.wikimedia.org/wiki/Category:Lascaux
- **License**: CC BY-SA 3.0 IGO (UNESCO license)
- **Note**: Original cave closed 1963; legally accessible replicas (Lascaux II/IV) are visually accurate
- **Features**: Hall of Bulls with dots, Fifth Bull with seven dots, Megaloceros with twelve dots
- **Period**: 17,000-22,000 years old (early Magdalenian)

### Egyptian Pyramids - Triangular Geometry

## Implementation Guide

### License Types Summary

**CC0 / Public Domain** (Most Permissive):
- No restrictions, no attribution required
- Best for: Maximum flexibility
- **Sources**: Met Museum Open Access, many historical images, Royal Ontario Museum images

**CC BY (Attribution)**:
- Attribution required, commercial use allowed, modifications permitted
- **Sources**: Some Wikimedia Commons images

**CC BY-SA (Attribution-ShareAlike)**:
- Attribution required, modifications allowed but must share under same license
- **Sources**: Most Wikimedia Commons images
- **Best for**: Educational and open-source projects

**CC BY-NC (Attribution-NonCommercial)**:
- Educational/academic use only, no commercial use
- **Sources**: Some academic institutions

### Direct URL Access Methods

**Wikimedia Commons**:
1. Navigate to file page
2. Click image to full size
3. Right-click and "Copy Image Address"
4. URL format: `https://upload.wikimedia.org/wikipedia/commons/[hash]/[filename]`

**Met Museum**:
1. Visit object page or use API: `https://collectionapi.metmuseum.org/public/collection/v1/objects/[ObjectID]`
2. JSON response includes `primaryImage` field with direct URL
3. All Open Access images marked with OA icon

**HTML Embedding Template**:
```html
<img src="https://upload.wikimedia.org/wikipedia/commons/[path]/[file].jpg" 
     alt="Description" 
     title="Source: [Institution], License: [License Type]">
```

### Attribution Templates

**For CC BY/CC BY-SA**:
"Image: [Title], by [Author], licensed under [License], via [Source]"

**For Public Domain**:
"Image: [Title], public domain, via [Source]"

**For Met Open Access**:
"Image courtesy of The Metropolitan Museum of Art Open Access"

### Resolution Recommendations

- **Web presentations**: 1920-3000 pixels wide
- **Print (standard)**: 3000-5000 pixels
- **Print (high-quality)**: 5000+ pixels
- **Mobile-responsive**: 800-1200 pixels thumbnails
- **SVG files**: Infinitely scalable (ideal for diagrams)

### Key Open Access Sources

**Best Overall**:
1. **Metropolitan Museum of Art**: CC0, comprehensive API, 26,000+ Egyptian objects, 500,000+ total
2. **Wikimedia Commons**: Largest free collection, various CC licenses
3. **Smithsonian Institution**: Open Access program, CC0 for many items
4. **National Gallery of Art**: Public domain policy, high-res downloads
5. **Royal Ontario Museum**: CC0 for many ethnographic objects

**Specialized Collections**:
- **British Museum**: Extensive but check individual licenses (typically CC BY-NC-SA 4.0)
- **UNESCO**: World Heritage documentation, CC BY-SA IGO 3.0
- **CDLI**: Cuneiform tablets, educational use with attribution
- **Gallica-BNF**: French national library, public domain historical images

### Important Notes

**Always Verify**: Check current license status on source pages before use, as policies can change

**Educational Use**: Most restrictive licenses still permit educational use with proper attribution
