# GECD 3D Timeline — Replit Build Specification

## Project Overview

Build a 3D interactive timeline visualization of **GECD (Geometric Element Civilization Development) nodes** — moments in history where geometry, civilization, and development converge. This is NOT a project management tool. It is a research visualization tool that plots archaeological and historical artifacts in three-dimensional space.

### Core Concept

Geometry (G) is the **central axis** — the spine of the visualization. The four remaining MAGIC drivers (Math, Aesthetic, Institutional, Comptroller) determine each node's position in Y/Z space relative to that spine. Time runs along X.

Each node represents a moment where a geometric element (circle, triangle, spiral, etc.) intersected with civilization development — a beveled-rim bowl, a ziggurat, a potter's wheel, a cylinder seal.

---

## Architecture

### Stack

| Layer | Technology | Why |
|-------|-----------|-----|
| **3D Engine** | Three.js | Industry standard, works in browser, massive community. Do NOT use Babylon.js or raw WebGL. |
| **Framework** | React + Vite | Fast dev, component model for UI panels. |
| **3D React binding** | @react-three/fiber + @react-three/drei | Declarative Three.js in React. Drei gives OrbitControls, Html overlays, Line, Text, etc. |
| **State** | Zustand | Lightweight, works perfectly with R3F. Not Redux. |
| **Data** | JSON flat files (initially) → Supabase (later) | Start simple. Each node is a JSON object. |
| **Styling** | Tailwind CSS | For the 2D UI panels (filters, detail view). |
| **Image pipeline** | Already exists in Replit project | Connects to Gemini/Imagen for artifact imagery. |

### MAGIC Driver Values

Each driver is a float from 0.0 to 1.0 representing how strongly that driver influenced this particular GECD node:

- **Math (M)**: Mathematical/computational significance (0 = none, 1 = primary mathematical breakthrough)
- **Aesthetic (A)**: Artistic/decorative significance (0 = purely functional, 1 = primarily aesthetic achievement)
- **Institutional (I)**: Institutional/organizational significance (0 = individual craft, 1 = civilization-scale system)
- **Comptroller (C)**: Economic/administrative significance (0 = no economic function, 1 = primary economic/accounting tool)

**G (Geometry) is NOT a driver value** — it is the categorical element assignment (circle, triangle, spiral, etc.) and determines the node's COLOR, not its position.

## 3D Coordinate System

### Axis Mapping

```
X-axis = TIME
  - Runs left (ancient) → right (modern)
  - Range: ~8000 BCE → 500 CE (adjustable)
  - Scale: logarithmic compression for deep time, 
    linear for dense periods (3500-1500 BCE)

Y-axis = INSTITUTIONAL + COMPTROLLER composite
  - These are the "civilization infrastructure" drivers
  - Y = (Institutional × weight) + (Comptroller × weight)
  - High Y = high organizational/economic significance
  - Low Y = individual/craft/non-institutional

Z-axis = MATH + AESTHETIC composite  
  - These are the "human expression" drivers
  - Z = (Math × weight) + (Aesthetic × weight)
  - High Z = high mathematical or artistic significance
  - Low Z = purely functional, no expressive dimension
```

### Why This Pairing

The Y/Z split creates a meaningful 2D cross-section at any time slice:

- **High Y, High Z** = Institutional + Expressive (ziggurats, palace reliefs)
- **High Y, Low Z** = Institutional + Functional (ration bowls, accounting tokens)
- **Low Y, High Z** = Individual + Expressive (decorative pottery, personal seals)
- **Low Y, Low Z** = Individual + Functional (hand tools, simple vessels)

The central G axis runs through the midpoint — geometry is always present, it's the *distribution* of the other forces that positions each node.

### The Central Spine

The G axis is visualized as a **glowing vertical line or tube** running along X at Y=0.5, Z=0.5 (the center of the MAGIC space). It represents pure geometry — the constant through all development. Nodes orbit around it at distances determined by their driver values.

## Visual Design

### Node Rendering

Each node is a **sphere** (or icosahedron for variety) with:

- **Color** = Geometric element assignment:
  - Circle (Shamash) → Gold/Amber `#F5A623`
  - 8-Pointed Star (Ishtar) → Deep Rose `#C62368`
  - Triangle (Enlil) → Storm Blue `#2B6CC4`
  - Square (Nabu) → Scribe Green `#2D8659`
  - Spiral (Tiamat) → Deep Ocean `#1A3A5C`
  - Arc (Anu) → Sky/Heaven `#7CB9E8`
  - Hexagon (Nisaba) → Grain Gold `#DAA520`
  - Pyramid (Marduk) → Royal Purple `#6A0DAD`

- **Size** = sum of all MAGIC driver values (total significance)
- **Opacity** = confidence level (well-attested = solid, speculative = translucent)
- **Glow/emissive** = on hover or selection

### Connections

Connections between related nodes rendered as **curved lines** (CatmullRomCurve3 or QuadraticBezier):

- Color: white at 30% opacity
- On hover of either connected node: brighten to 80%
- Line thickness: 1px default, 2px on highlight

### Background and Atmosphere

- Dark background: near-black with subtle blue undertone `#0A0E1A`
- Subtle grid on the X-Y plane (ground plane) with very low opacity
- Star-field particle system in deep background (optional, adds depth)
- Fog/distance fade for depth perception

### Time Axis Labels

- Major era labels floating along X axis: "Ubaid", "Uruk", "Early Dynastic", "Akkadian", "Ur III", "Old Babylonian", etc.
- Year markers at key intervals
- Use drei's `<Text>` or `<Html>` for labels

## Key Implementation Details

### Position Calculation (coordinates.js)

```javascript
// Convert MAGIC driver values to 3D position
export function magicToPosition(node, timeScale) {
  const { date_bce, date_ce, magic_drivers } = node;
  const { math, aesthetic, institutional, comptroller } = magic_drivers;
  
  // X = time (use timeScale function for log/linear hybrid)
  const x = timeScale(date_bce ? -date_bce : date_ce);
  
  // Y = Institutional-Comptroller axis
  // Weighted: institutional is primary, comptroller modulates
  const y = (institutional * 0.6 + comptroller * 0.4) * SPACE_SCALE;
  
  // Z = Math-Aesthetic axis  
  // Weighted: neither dominates
  const z = (math * 0.5 + aesthetic * 0.5) * SPACE_SCALE;
  
  return [x, y, z];
}

const SPACE_SCALE = 10; // World units for the Y/Z spread
```

### Time Scale (timeScale.js)

```javascript
// Hybrid log-linear scale for archaeological time
// Dense period (3500-1500 BCE) gets more space
export function createTimeScale(minYear, maxYear, worldWidth) {
  return function(year) {
    // Normalize to 0-1 range
    const t = (year - minYear) / (maxYear - minYear);
    // Apply slight log compression for deep time
    const compressed = Math.sign(t - 0.5) * 
      Math.pow(Math.abs(t - 0.5) * 2, 0.8) / 2 + 0.5;
    return (compressed - 0.5) * worldWidth;
  };
}
```

### GECDNode Component (simplified)

```jsx
function GECDNode({ node, position, color, isSelected, onSelect }) {
  const meshRef = useRef();
  const [hovered, setHovered] = useState(false);
  
  const size = useMemo(() => {
    const { math, aesthetic, institutional, comptroller } = node.magic_drivers;
    return 0.1 + (math + aesthetic + institutional + comptroller) * 0.1;
  }, [node]);

  return (
    <mesh
      ref={meshRef}
      position={position}
      onClick={() => onSelect(node.id)}
      onPointerOver={() => setHovered(true)}
      onPointerOut={() => setHovered(false)}
      scale={hovered ? 1.3 : 1}
    >
      <icosahedronGeometry args={[size, 2]} />
      <meshStandardMaterial
        color={color}
        emissive={color}
        emissiveIntensity={hovered || isSelected ? 0.5 : 0.1}
        transparent
        opacity={node.confidence || 1}
      />
      {hovered && (
        <Html distanceFactor={15}>
          <div className="tooltip">{node.name}<br/>{node.date_display}</div>
        </Html>
      )}
    </mesh>
  );
}
```

## Zustand Store

```javascript
import { create } from 'zustand';

const useGECDStore = create((set, get) => ({
  // Data
  nodes: [],
  connections: [],
  
  // Filters
  filters: {
    elements: ['circle','star','triangle','square','spiral','arc','hexagon','pyramid'],
    timeRange: [-8000, 500],
    magicThresholds: { math: 0, aesthetic: 0, institutional: 0, comptroller: 0 },
  },
  
  // Selection
  selectedNodeId: null,
  hoveredNodeId: null,
  
  // Camera presets
  cameraPreset: 'default', // 'default' | 'top' | 'side' | 'front'
  
  // Actions
  setNodes: (nodes) => set({ nodes }),
  selectNode: (id) => set({ selectedNodeId: id }),
  hoverNode: (id) => set({ hoveredNodeId: id }),
  
  setElementFilter: (elements) => set(s => ({ 
    filters: { ...s.filters, elements } 
  })),
  
  setTimeRange: (range) => set(s => ({ 
    filters: { ...s.filters, timeRange: range } 
  })),
  
  // Computed: filtered nodes
  getFilteredNodes: () => {
    const { nodes, filters } = get();
    return nodes.filter(n => {
      if (!filters.elements.includes(n.geometric_element)) return false;
      const year = n.date_bce ? -n.date_bce : n.date_ce;
      if (year < filters.timeRange[0] || year > filters.timeRange[1]) return false;
      const m = n.magic_drivers;
      if (m.math < filters.magicThresholds.math) return false;
      if (m.aesthetic < filters.magicThresholds.aesthetic) return false;
      if (m.institutional < filters.magicThresholds.institutional) return false;
      if (m.comptroller < filters.magicThresholds.comptroller) return false;
      return true;
    });
  },
  
  // Connection to image pipeline
  sendToImagePipeline: (nodeId) => {
    const node = get().nodes.find(n => n.id === nodeId);
    if (node) {
      // Hook into existing image pipeline
      console.log('Sending to image pipeline:', node.image_prompt);
      // TODO: connect to existing Replit image pipeline endpoint
    }
  },
}));
```

### Existing Timeline

If you have partial timeline code, the key integration point is the **position calculation**. Replace any existing 2D positioning with the `magicToPosition()` function above. The 3D nodes should use the same data source as your existing timeline — just rendered in Three.js space instead of flat SVG/Canvas.

### Research Ingestion

When new research is ingested:
1. Parse the research for artifact references
2. Create a new GECD node object (or update existing)
3. Assign MAGIC driver values (can be AI-assisted)
4. Add to nodes.json / data store
5. Node appears in 3D space automatically via React reactivity

## Performance Notes

- For < 100 nodes: no optimization needed
- For 100-500 nodes: use InstancedMesh for identical geometries
- For 500+: implement LOD (Level of Detail) — far nodes become points
- Connection lines: use a single LineSegments geometry, not individual Line components
- Use React.memo on GECDNode to prevent unnecessary re-renders
