## A1: Myth Hook (5–8 min)

**MAGIC signature needed:** `[0.1, 0.6, 1.0, 0.9, 0.2]` - High I (mythology), High A (visual), Low C

### Artifact Requirements:
- Relief carving showing deity + geometric element
- Statue or stele with deity iconography
- Temple wall art depicting mythological scene
- Votive object with deity symbol

### Image Search Keywords (Shamash/Circle example):
```
"Shamash relief"
"Shamash sun disk" 
"Neo-Assyrian sun god"
"Mesopotamian solar deity carving"
"Shamash Tablet"
"sun disk rays Mesopotamia"
"divine justice symbol ancient Iraq"
```

### Image Search Keywords (Ishtar/8-Star example):
```
"Ishtar 8-pointed star"
"Inanna star symbol"
"Venus goddess Mesopotamia"
"eight-pointed star cylinder seal"
"Ishtar Gate star"
"cuneiform star deity"
```

### Video/Animation Requirements:
- **Scene 1:** Deity introduction (5-10 seconds) - statue or relief shown
- **Scene 2:** Problem presented (10-15 seconds) - narrative context
- **Scene 3:** Geometric element solves problem (15-20 seconds) - element highlighted, animated if possible
- **Scene 4:** Element = symbol established (5-10 seconds) - element isolated, named

**Motion study:** Pan across relief showing element, zoom to emphasize geometric form

## A2: Metaphor Intelligence (5–8 min)

**MAGIC signature needed:** `[0.3, 0.9, 1.0, 0.5, 0.2]` - High A (artistic technique), Moderate M (properties)

### Artifact Requirements:
- Close-up detail shots of element in different artifacts
- Multiple instances showing same geometric property
- Examples where property creates specific visual effect

### Image Search Keywords (Circle/Shamash example):
```
"Mesopotamian rosette pattern"
"circular sun disk detail"
"radial symmetry ancient Near East"
"equidistant rays carving"
"concentric circles Mesopotamia"
"cylinder seal circular motif close-up"
```

### Diagram Requirements:
**Diagram 1: Property Identification**
- Element isolated on white background
- Key geometric properties labeled with arrows
- Example: Circle with center marked, radius lines drawn, "all points equidistant" annotation

**Diagram 2: Perceptual Affordance**
- Split view: geometric property → perceptual effect
- Example: "Equal radii → Visual equilibrium (eye travels equally in all directions)"
- Use color or shading to show how eye moves across form

**Diagram 3: Cultural Exploitation**
- Side-by-side: property + artifact usage
- Example: "Radial equality" property next to "Justice reaches all" Shamash depiction

**Motion study:** 
- Animate eye movement across geometric form
- Show symmetry operation (rotation, reflection) highlighting property
- Trace visual flow created by geometric property

- 5-8 different artifacts all showing same element
- Mix of media: relief, painting, sculpture, seal impression
- Range of contexts: temple, palace, portable object
- Clear deity identification possible

### Image Search Keywords (Shamash/Circle example):
```

"Neo-Assyrian solar deity throne"
"Akkadian sun god stele"
"Shamash iconography museum"
"Mesopotamian sun disk temple"
"divine rays sculpture ancient Iraq"
```

### Artifact Analysis Grid Requirements:
**For each artifact, provide:**
- **Image:** High-res, well-lit, artifact clearly visible
- **Element location:** Marked/circled in image
- **Artifact type:** (cylinder seal, wall relief, votive statue, etc.)
- **Findspot:** (Sippar temple, Nineveh palace, etc.)
- **Date:** (Neo-Assyrian period, 883-612 BCE)
- **Current location:** (British Museum, Louvre, etc.)
- **Technique visible:** (carved relief, molded clay, cast bronze, etc.)
- **Perceptual effect:** (from A2) - how property works here

### Motion study:
- Cursor/pointer moves across artifact highlighting element
- Zoom in on element detail
- Overlay showing geometric analysis (center, radii, symmetry)

### Technique Demonstration Requirements:
**Video/Photo sequence showing:**
1. Tool preparation (5-8 images)
2. First mark/cut (5-8 images)
3. Mid-process (5-8 images)
4. Completion (5-8 images)
5. Final result next to ancient example

**For each step, show:**
- Hand position
- Tool angle
- Material response (clay deformation, stone chipping, etc.)
- Geometric accuracy check points

### Diagram Requirements:
**Diagram 1: Tool Mechanics**
- Technical drawing of tool
- How it creates geometric property
- Force/motion arrows
- Labeled parts

**Diagram 2: Construction Steps**
- Geometric construction sequence (1, 2, 3, 4...)
- Each step adds one element
- Final overlay shows complete form
- Ancient example for comparison

### Motion study:
- Hands performing technique in real-time
- Slo-mo for critical moments (compass pivot, tool contact)
- Split screen: student hands + ancient artifact result
- Time-lapse of full process (30 seconds compressed to 5)

## A7: Art Activity + Bridge Artifact (15–20 min)

**MAGIC signature needed:** `[0.5, 0.9, 1.0, 0.5, 0.3]` - High A (creation), Moderate M (bridge to function)

### Artifact Requirements (Bridge Artifact):
**Must have BOTH:**
1. Visual/decorative use of element (Day A)
2. Structural/functional use of element (Day B)

**Examples:**
- Cathedral rose window: decorative rosette pattern + structural stone tracery using circles
- Mesopotamian ziggurat: decorative corner volutes + structural stepped pyramid using rectangles
- Islamic dome: decorative muqarnas patterns + structural arch geometry
- Greek temple: decorative frieze circles + column circular cross-sections

### Image Search Keywords (Rose window bridge example):
```
"cathedral rose window"
"Gothic circular tracery"
"stained glass geometric pattern"
"stone framework rose window"
"structural elements Gothic window"
"flying buttress support"
"rose window construction"
"Gothic engineering diagrams"
```

### Bridge Question Image Requirements:
**Two views of same artifact:**
1. **Decorative view:** Full color, lit to show beauty, pattern emphasis
2. **Structural view:** X-ray, diagram, engineering drawing showing how it stands

**Caption for view 1:** "The rose window creates a beautiful circular pattern with radial symmetry"
**Caption for view 2:** "But how does the window stay up? What prevents the heavy stone from falling?"

### Student Creation Template:
- Blank space matching artifact format
- Grid or guides for geometric accuracy
- Example of completed work alongside
- Materials list with quantities
- Time estimate

### Motion Study Requirements (CRITICAL FOR B3):
**Animation 1: Transformation in Action**
- Element in starting position (0° or initial state)
- Transformation applied smoothly (rotation, reflection, translation)
- Multiple frames showing intermediate states
- Final position/state shown
- Ability to replay, slow-mo, pause

**Animation 2: Property Preservation**
- Element transforms
- Key property highlighted throughout (stays constant)
- Split screen: element changing | property unchanging
- Annotations: "Shape moves BUT [property] stays the same"

**Animation 3: Real-World Application**
- Tool/machine performing transformation
- Element visible throughout
- Result shown alongside starting state

### Diagram Requirements:
**Transformation Sequence:**
- 5-8 frames showing transformation
- Arrows indicating motion direction
- Angle measurements (if rotation)
- Distance measurements (if translation)
- Before/after comparison panel

### Narrative Visual Requirements:
**3-Panel Story:**
1. **The Problem:** Image showing difficulty/limitation before invention
2. **The Solution:** Image showing invention/breakthrough
3. **The Impact:** Image showing transformation enabled

Each panel needs:
- High-quality artifact image
- Diagram showing geometric principle
- Caption with date, place, innovator (if known)

### Invention Analysis Diagram:
- **Problem statement:** What couldn't be done?
- **Constraint diagram:** Why? (geometric limitation shown)
- **Element property:** Which geometric property solved it?
- **Solution diagram:** How? (element applied to problem)

## IMAGE SEARCH STRATEGY BY DRIVER SIGNATURE

**High I artifacts (mythology, belief) - search terms:**
- Add deity names
- Add "ritual", "votive", "temple", "sacred"
- Add "cult object", "religious", "ceremonial"
- Museum collection focus: Ancient Near East, religious objects

**High C artifacts (power, control) - search terms:**
- Add "royal", "palace", "king", "elite"
- Add "monumental", "kudurru", "boundary stone"
- Add "inscription", "ruler name"
- Museum collection focus: Palace contexts, royal burials

**High A artifacts (aesthetic, artistic) - search terms:**
- Add "decorative", "ornamental", "pattern"
- Add specific motifs: "rosette", "geometric", "design"
- Add material craft terms: "carved", "molded", "painted"
- Museum collection focus: Art/decorative arts departments

**High M artifacts (mathematical, functional) - search terms:**
- Add "construction", "engineering", "tool"
- Add "mechanism", "device", "machine"
- Add "measurement", "precision", "calculation"
- Museum collection focus: Technology, tools, scientific instruments
