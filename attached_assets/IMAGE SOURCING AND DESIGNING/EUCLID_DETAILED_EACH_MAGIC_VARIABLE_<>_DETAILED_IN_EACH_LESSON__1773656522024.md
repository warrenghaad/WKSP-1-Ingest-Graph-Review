# SECTION KNOWN COMPLEX — MAGIC Ecosystem & Artifact Research Templates
## Framework v5.1 Alignment | All 14 Sections

**Purpose:** For each lesson section, this document maps (1) what every MAGIC thread is DOING at that argument step, (2) what GE abstractions are active, (3) parameterized keyword searches for automated artifact/image discovery, and (4) the bridge forward that must be established before the next section can land.

**Keyword Template Variables:**
- `{CIV}` — Civilization name (e.g., Mesopotamia, Sumer, Akkad, Babylon)
- `{GEA}` — Geometric Element Atomic (e.g., circle, 8-pointed star, triangle, spiral)
- `{GEM}` — Geometric Element Molecular (e.g., rosette, guilloche, tessellation, meander)
- `{DEITY}` — Associated deity or mythic figure (e.g., Shamash, Ishtar, Enki, Marduk)
- `{CARRIER}` — Material carrier (e.g., cylinder seal, pottery, stele, textile, tablet)
- `{INVENTION}` — Functional invention (e.g., potter's wheel, arch, irrigation canal, plow)
- `{GEK}` — Geometric principle (e.g., radial symmetry, rotational force, compression, tessellation)
- `{PERIOD}` — Historical period (e.g., Uruk Period, Early Dynastic, Old Babylonian)
- `{SITE}` — Archaeological site (e.g., Ur, Uruk, Nippur, Babylon)
- `{MATERIAL}` — Material medium (e.g., clay, lapis lazuli, bronze, bitumen, gypsum)

## THE ARGUMENT STRUCTURE

The 14-section structure is not a lesson sequence. It is a logical argument that happens to be pedagogy.

```
DAY A: THE METAPHOR CASE

A1: PROBLEM    — Power deploys ideology to solve existential problems
A2: MECHANISM  — The solution is made visible through geometric design
A3: EVIDENCE   — The mechanism at peak intensity (iconographic masterworks)
A4: SCALE      — The mechanism distributed into daily life (internalized civilization)
A5: EMBODIMENT — Students acquire the spatial technique themselves
A6: PRACTICE   — Students produce original work
A7: THESIS     — Architecture proves both registers coexist

DAY B: THE FUNCTION CASE

B1: RESET      — Recall the claim; reorient to function
B2: FORMALIZE  — The mathematics underneath
B3: MECHANICS  — What the element does when it moves
B4: INVENTORY  — G(t-1): what the culture could already do
B5: PIVOT      — The ingenuity delta: the one addition that changed everything
B6: REPLICATE  — Students replicate the ingenuity
B7: RECURSE    — This G becomes next week's G(t-1)
```
