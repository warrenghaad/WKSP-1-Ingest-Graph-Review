# GEA/GEM Taxonomy — Core Geometric Elements

## GEA Primitives (Atomic)

| GEA Code | Element | Key Properties | Perceptual Affordance |
|----------|---------|---------------|----------------------|
| GEA.circle | Circle | Equidistance, constant curvature, π, infinite symmetry | Completeness, wholeness, cycle, perfection, containment |
| GEA.line | Line (straight) | Direction, shortest path, infinite extension | Connection, boundary, division, trajectory |
| GEA.triangle | Triangle | Minimum polygon, rigid structure, 180° angle sum | Stability, hierarchy, pointing/direction, three-ness |
| GEA.square | Square | Equal sides, right angles, tileability, D₄ symmetry | Order, foundation, enclosure, earthly stability |
| GEA.arc | Arc | Partial circle, curvature without closure | Opening, incompleteness, crescent, transition |
| GEA.spiral | Spiral | Continuous curve with increasing/decreasing radius | Growth, unfolding, time, organic development |
| GEA.hexagon | Hexagon | Optimal packing, 120° angles, D₆ symmetry | Efficiency, natural order, cellular structure |
| GEA.parallel | Parallel lines | Equidistant, non-intersecting, direction-preserving | Rhythm, repetition, rails, channeling |
| GEA.cross | Cross | Perpendicular intersection, four quadrants | Intersection, division of space, cardinal directions |
| GEA.ellipse | Ellipse | Two foci, varying curvature, orbital path | Elongation, orbit, dynamic balance |

## GEM Compositions (Molecular)

GEMs are formed by combining GEAs through interaction rules. Each GEM has:
- **Component GEAs** — what primitives compose it
- **Interaction rule** — how they combine (superposition, rotation, reflection, intersection, containment, tangency)
- **Emergent properties** — what the composition has that no component has alone

### Common GEM Patterns

| GEM Code | Composition | Interaction Rule | Emergent Property |
|----------|------------|-----------------|-------------------|
| GEM.rosette | GEA.circle + GEA.line (radial) | Radial subdivision | n-fold symmetry, emanation pattern |
| GEM.8star | GEA.square × 2 | Superposition + 45° rotation | D₈ symmetry, octagonal intersection |
| GEM.6star | GEA.triangle × 2 | Superposition + 180° rotation | D₆ symmetry, hexagonal intersection |
| GEM.tessellation | GEA.[any tileable] × n | Translation + edge-matching | Infinite extensibility, plane-filling |
| GEM.concentric | GEA.circle × n | Shared center, varying radius | Hierarchy, target, radiation levels |
| GEM.meander | GEA.line + GEA.line | Perpendicular zigzag pattern | Labyrinth, infinite path in bounded space |
| GEM.guilloche | GEA.circle × 2+ | Overlapping offset circles | Interference pattern, woven appearance |
| GEM.volute | GEA.spiral + GEA.spiral | Mirror reflection of spirals | Bilateral growth, architectural capital |
| GEM.trefoil | GEA.arc × 3 | 120° rotational arrangement | Three-fold organic unity |
| GEM.quatrefoil | GEA.arc × 4 | 90° rotational arrangement | Four-fold containment |

| Level | Rendering | Example | Carrier Constraint |
|-------|-----------|---------|-------------------|

## GEK-T Transformation Tiers

| Tier | Operations | Example |
|------|-----------|---------|
| Tier 1 | Single: rotation OR reflection OR scaling OR translation | Rotating a seal 90° |
| Tier 2 | Combined: rotation + reflection, scaling + translation | Creating a frieze pattern |
| Tier 3 | Chained with feedback: operation output feeds next input | Tessellation from seed motif |

## Decomposition Protocol

For any GEM encountered in the archaeological record:

1. **Identify constituent GEAs** — what primitives are present?
2. **Identify interaction rules** — how do they combine?
3. **Identify dimensional rendering** — what level?
4. **Identify carrier constraints** — how does the carrier shape possibilities?
5. **Identify GEK-T tier** — what transformations produced this?
6. **Identify construction sequence** — what order were operations performed?
7. **Assess formalization state** — is this composition explicitly documented in period texts, or only empirically practiced?
