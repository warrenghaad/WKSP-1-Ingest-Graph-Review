# AGENT: A7 — Dual-Register Reveal
## The Pivot

**Role:** Bridge between metaphorical comprehension and functional understanding; reveals that the same geometric form simultaneously signifies meaning AND enables mechanical/mathematical action
**Priority:** CRITICAL — Day A closure and Day B gateway; student recognizes geometry as dual-register phenomenon
**Cognitive Operation:** REVEAL + PIVOT — "Can you see this form doing BOTH things at once — meaning something AND making something work?"
**Register:** metaphor → transitional
**MAGIC Weight:** [M:0.5, A:0.7, G:0.9, I:0.7, C:0.6]

**Skills this agent calls:**
- S2: Annotate for Dual Register (metaphor + function overlay)
- S4: Geometric Decomposition (same A2 decomposition, re-framed)
- S6: Visual Annotation & Markup (dual-color annotation overlay)

## DELIVERABLES CHECKLIST (4 components + 5 distillation artifacts = 9 total)

### Component 1: Architectural Artifact Presentation
| Deliverable | Format | Description |
|-------------|--------|-------------|
| Full Site Documentation | MUS (Museum/Site Image) | Large-scale engineered structure with complete metadata: location, construction date, dimensions, materials, construction technique, patron/designer attribution, current preservation condition. Photograph must show entire artifact in context. |
| Site Context Data | Structured Metadata | Location coordinates, historical period, architectural style classification, original function, current use, accessibility information. |
| Artifact Scale Reference | Dimensional Notation | Height/width/length in both metric and historical units; site footprint; individual component dimensions that relate to A2 decomposition. |

### Component 2: Dual-Register Annotation Diagram
| Deliverable | Format | Description |
|-------------|--------|-------------|
| Split-View Decomposition | DGM (Diagram) | Left side: A2 decomposition with metaphorical reading and principle; Right side: same geometry reframed with functional properties highlighted. Center column: shared geometry markup showing identical structure in both registers. |
| Annotation Legend | Text Reference | Color key for metaphor register (warm colors) vs. function register (cool colors); symbol key for geometric relationships that serve both purposes. |
| Geometry Bridge Callouts | Visual Annotations | 3-4 specific points on the diagram where the SAME geometric feature carries both metaphorical meaning AND functional property. |

### Component 3: Dual Overlay Visualization
| Deliverable | Format | Description |
|-------------|--------|-------------|
| Transparent Overlay Image | OVR (Overlay Image) | Original architectural photograph with dual-register annotations applied simultaneously: metaphor in designated color (e.g., warm gold), function in designated color (e.g., cool blue). Overlay transparency should allow base architecture to show through. |
| Overlay Methodology Documentation | Text Explanation | Brief explanation of how the overlay was constructed, which geometric features are highlighted in which register, and how the student should read the dual presentation. |

### Component 4: Pivot Narrative
| Deliverable | Format | Description |
|-------------|--------|-------------|
| Reveal Moment Text | Narrative (3-4 paragraphs) | Student-facing text that articulates the pivot moment: "This shape MEANS [A2 principle] AND it also DOES [functional property]. Same geometry. Both registers true simultaneously. You've been seeing both all along — now you see HOW." Written at grade level with concrete language. |
| Cognitive Verification | Reflection Prompt | Guided question for student self-check: "Show me one place on this building where you can point to a shape and say 'that means _____ AND it also makes _____ work.'" |
| B1 Bridge Seed | Explicit Handoff | Statement that seeds Day B register shift: "Tomorrow we're asking a different question: if this shape DOES that, what does that tell us about how it's built? What rule does it follow?" |

### Distillation Artifacts
| Deliverable | Content |
|-------------|---------|
| A7 Summary Card | One-page visual summary: artifact image (top half), dual-register principle statement (bottom half), metaphor/function labels clearly marked. |
| Geometry Comparison Matrix | Table: Feature Name \| A2 Metaphorical Reading \| A7 Functional Property \| Evidence from Artifact. 4-5 rows. |
| Student Discovery Guide | Worksheet structure: "Find these three features on the building. For each: Write what it MEANS. Write what it DOES. Can both be true?" |
| Annotation Key | Reference sheet for all notation used in DGM and OVR deliverables; essential for independent student review. |
| Day A→Day B Transition Script | Teacher-facing 2-3 paragraph script for closing Day A and opening Day B conversation, referencing specific A7 artifacts. |

## QUALITY CHECKLIST
- [ ] Architectural artifact is large-scale engineered structure (not decorative); full site data documented
- [ ] MUS image shows entire artifact in clear context with scale reference visible or annotated
- [ ] Artifact is the SAME entity from A2's composition (not a new example)
- [ ] DGM split-view clearly shows LEFT/metaphor RIGHT/function with CENTER shared geometry
- [ ] Overlay transparency allows base architecture to show through (not opaque color blocks)
- [ ] Pivot narrative is 3-4 paragraphs, grade-appropriate language, student-facing tone
- [ ] Pivot narrative explicitly states "same geometry, both true simultaneously" (not "metaphor becomes function")
- [ ] B1 Bridge Seed statement is present and specific enough to launch Day B
- [ ] All four components align on identical geometric features (no inconsistencies between DGM and OVR)
- [ ] Distillation artifacts include both student-facing (Discovery Guide, Summary Card) and teacher-facing (Transition Script) materials
- [ ] No component claims that metaphor "transforms into" or "becomes" function — both registers always coexist
- [ ] Quality check: Read pivot narrative aloud; does student hear "wait, BOTH?" or "then metaphor changes to function?"
