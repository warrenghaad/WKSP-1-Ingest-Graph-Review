# AGENT: B1 — Bridge
## Register Shift

**Role:** Minimal but precise handoff from Day A (metaphorical) to Day B (functional) register; student acknowledges dual geometry, then shifts cognitive frame to mechanical/mathematical inquiry
**Priority:** ESSENTIAL — continuity anchor; without explicit A7 reference, Day B appears disconnected from Day A
**Cognitive Operation:** PRESENT (Function) — "What question opens when we ask not 'what does this mean' but 'what does this do'?"
**Register:** function
**MAGIC Weight:** [M:0.3, A:0.5, G:0.6, I:0.5, C:0.2]

**Skills this agent calls:**
- S1: Artifact Reference & Citation (A7 artifact recall)
- S5: Question Design (B2 functional hook)

from_A7:

## DELIVERABLES CHECKLIST (3 components + 5 distillation artifacts = 8 total)

### Component 1: A7 Recall Block
| Deliverable | Format | Description |
|-------------|--------|-------------|
| A7 Image Reference | Visual Citation | Reprint or reference to A7's primary architectural image (MUS or OVR) — the artifact students examined yesterday. Caption reminder: "Yesterday you discovered that this [specific shape] means [A2 principle] AND does [A7 function]." |
| A7 Principle Restatement | Text (1 paragraph) | Concise restatement of what students learned in A7: dual-register recognition. Concrete, specific, uses student language if possible ("you noticed," "you saw," "you discovered"). |
| Memory Anchor Question | Reflection Prompt | Simple verification question: "Can you point to one place on this artifact that shows both the meaning AND the action?" Answer-seeking (not rhetorical). |

### Component 2: Register Shift Statement
| Deliverable | Format | Description |
|-------------|--------|-------------|
| The Reframing | Narrative (1-2 paragraphs) | Student-facing text: "Yesterday we asked 'what does this MEAN?' Today: 'what does this DO?' Same building. Same shape. New question." Friendly, direct, no jargon. Explicitly reference A7's dual discovery. |
| Register Change Justification | Text (1 paragraph) | Why ask a different question? Because function enables prediction, design, understanding of constraints. Subtle pitch for why Day B matters. NOT "we're leaving metaphor behind" — more "we're asking what the metaphor enables." |
| Tone Shift Permission | Implicit Frame | Signal that Day B will use measurement, geometry, notation — different tools, same artifact. Normalize tool-switching. |

### Component 3: Functional Hook
| Deliverable | Format | Description |
|-------------|--------|-------------|
| B2 Question Preview | Text (1 brief statement) | Explicit seed of B2's inquiry: "If this shape DOES [A7 function], what's the rule? What property must it have? How do we measure it? How do we PROVE it works?" One or two of these questions, grade-appropriate. |
| Why This Question Matters | Text (1 paragraph) | Connect to student stakes: discovering the rule means you can predict, build, check, modify. This is how engineers think. |
| Day B Doorway | Transition Phrase | Bridge language: "Let's find out." / "Let's test." / "Let's measure." Sets expectation for Day B cognitive operation (DEFINE). |

### Distillation Artifacts
| Deliverable | Content |
|-------------|---------|
| B1 One-Pager | A7 artifact image (top), register shift statement (middle), B2 functional hook question (bottom). Single page. |
| Day A→Day B Conversation Bridge | 3-4 sentence teacher script for opening Day B: "Show A7 artifact. Ask memory anchor question. State register shift. Ask B2 hook question. Listen for student response." |
| Register Definition Handout | Glossary/reference: What we mean by "metaphor register" vs. "function register" with examples from this specific artifact. For student or teacher use. |
| Visual Transition Graphic | Simple two-arrow diagram: DAY A (metaphor question mark) ← SAME ARTIFACT → DAY B (function question mark). Not explanatory, just directional. |
| B2 Preparation Checklist | Teacher preparation: "Before Day B, students should be able to: (1) name the A7 artifact, (2) state one thing it MEANS, (3) state one thing it DOES, (4) ask one question about HOW it does that." |

## QUALITY CHECKLIST
- [ ] A7 recall block references SPECIFIC artifact, SPECIFIC principle, SPECIFIC function (not generic)
- [ ] Register shift statement is short (1-2 paragraphs); does NOT feel rushed or abrupt
- [ ] Register shift statement explicitly acknowledges A7 ("yesterday," "discovered," "same geometry")
- [ ] B2 functional hook question is grade-appropriate and answerable through observation
- [ ] Tone is inviting, not demanding; "let's discover" not "now we abandon metaphor"
- [ ] No component dismisses or diminishes Day A / metaphorical understanding
- [ ] Day B Doorway phrase sets tone for Day B's DEFINE cognitive operation (not REVEAL)
- [ ] All distillation artifacts are SHORT (one-pagers, bullet points, scripts — not essays)
- [ ] Teacher script is usable in 2-3 minutes of class time
- [ ] Quality check: Read B1 aloud; does student hear "we're asking a different question about the same thing" or "we're moving on from metaphor"?
- [ ] B1 total should feel brief, purposeful, not like a full lesson — it's a bridge, not a destination
- [ ] A7 image reference is visually clear and immediately recognizable to students
