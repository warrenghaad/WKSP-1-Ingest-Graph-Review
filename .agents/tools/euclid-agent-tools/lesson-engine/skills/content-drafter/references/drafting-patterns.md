# Drafting Patterns

## Level 5 (eTextbook) Pattern

Level 5 is the MASTER — everything exists here. Structure:

```
[Section Title]

[Opening narrative — hooks into the section's cognitive operation]

[Core content — 2-4 paragraphs performing the cognitive operation]
  - Embedded GEA/GEM notation in natural language
  - Image references: "See [Image: artifact_name, Museum, Accession#]"
  - MAGIC tags as invisible metadata: <!-- m_definition, g_formal_properties -->

[Discussion Prompt]
"[Question that advances the cognitive operation]"

[Vocabulary]
- Term: Definition calibrated to grade level

[Extension Material]
[Additional depth for advanced students or teacher enrichment]
```

## Level 4 (Teacher Script) Pattern

```
[Section Title] — [Duration: X minutes]

TEACHER SAYS:
"[Opening script calibrated to grade level]"

[0:00-1:30] SHOW: [Image reference]
"[What to say while showing this image]"

ANTICIPATED RESPONSES:
- Student might say: "[common response]" → Redirect: "[teacher redirect]"
- Student might say: "[misconception]" → Clarify: "[correction]"

DIFFERENTIATION:
- Struggling: [simpler version]
- Advanced: [extension question]

TRANSITION: "[Bridge sentence to next section]"
```

## Level 3 (Slideshow) Pattern

```
SLIDE 1: [Image]

SLIDE 2: [Diagram or Image]
[1-2 sentence caption]

SLIDE 3: [Key Question]
"[Question that students discuss]"
```

## Level 1 (Teacher Summary) Pattern

```
[Section Code]: [Section Name]
Element: [name]
Concept: [one sentence]
Artifact: [name, museum, accession]
Connection: [to upstream/downstream section]
Duration: [minutes]
```

## Writing Principles

1. **Visual-first**: Write as if the image is the content and you're adding captions
2. **Cognitive operation fidelity**: Every paragraph must serve the section's named operation
3. **GEA/GEM integration**: Notation appears naturally, not as an appendix
4. **Grade calibration**: Same structure, different vocabulary depth
5. **Structural awareness**: Reference upstream sections, set up downstream sections
